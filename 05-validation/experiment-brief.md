# The Validation · FinWise

> Module 5 · Experimentation Methods. The experiment brief that tests the bet.

## Method

**Method:** Multi-Armed Bandit

**Why:** For this experiment, as we cannot afford conversion loss and we need a result in the next 2-3 weeks to impact conversion we prefer to go with a Multi-Armed Bandit. We assume we have the algorithm and the tech implemented to run it.

_____

## Hypothesis + primary metric

If we introduce a personalized onboarding experience that guides FinWise trial users toward importing their financial data and discovering value through collaboration, we expect more users to reach their first Aha Moment, as measured by an increase in the Data Import completion rate (%).

**Primary metric:** weekly Import completion rate, target: A 15% increase of import completion rate

_Experiment: Activation during onboarding test, Show the core value of FinWise during Onboarding and be able to move the metric from Trial to paid._

_Testing 3 arms: 
Showing: 
1. Questionnaire before import 
2. Video tutorial before import 
3. Checklist and shared with teammates 
Always in a base of collaboration on Trial users. Current experience: Onboarding now is asking just to import after registration._

_Predicted outcome: We predict that the Data Import completion rate will increase over the next two weeks, leading to an improvement in Trial-to-Paid conversion over time. If successful: If a prompt variant wins, we will adopt it and run a follow-up experiment to further improve activation and Trial-to-Paid conversion.

For example:

Video wins: Test different video content or messaging.

Questionnaire wins: Test different personalization questions.

Checklist wins: Test different checklist steps or sequences.

The goal is to iteratively optimize the winning experience and measure whether each improvement drives higher Data Import completion and, ultimately, Trial-to-Paid conversion. If unsuccessful: Review where users start but fail to complete the data import process, identify any errors or friction points, and reassess whether collaboration is the right approach to helping users experience product value. If the hypothesis is not validated, explore an alternative growth loop and run a follow-up experiment to test its impact on activation and Trial-to-Paid conversion._

_____

## Guardrail + read date

- **Guardrail:** Minimum 1% to 5% of traffic per arm
- **Read date:** in the next 2-3 weeks (Trial will need to finish to also see the impact)
